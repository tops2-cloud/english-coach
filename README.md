# 🦉 Language Coach

แอพฝึกภาษาสำหรับคนไทย ใช้บนมือถือผ่านเบราว์เซอร์ได้เลย

- **อังกฤษ** 2 ระดับ: ผู้เริ่มต้น (ชีวิตประจำวัน) และ คนทำงาน (ประชุม อีเมล สัมภาษณ์)
- **เกาหลี ญี่ปุ่น จีน เวียดนาม** ระดับผู้เริ่มต้น (ชีวิตประจำวันและท่องเที่ยว) พร้อมคำอ่านโรมัน/โรมาจิ/พินอิน
- เลือกภาษาได้ที่ปุ่มมุมขวาบน ความคืบหน้าและความจำของครู AI แยกตามภาษา

## มีอะไรบ้าง

| ส่วน | ทำอะไร |
|---|---|
| 🏠 หน้าหลัก | XP วันนี้ เป้ารายวัน (50 XP) จำนวนวันติดต่อกัน กราฟ 7 วัน และสถิติรวม |
| 🃏 คำศัพท์ | แฟลชการ์ดพร้อมเสียงอ่าน ระบบทบทวนตามรอบ (spaced repetition) วันละ 10 คำใหม่ |
| ✅ ควิซ | ไวยากรณ์ 4 ตัวเลือก อธิบายภาษาไทยทุกข้อ ส่งข้อที่ผิดให้ครู AI อธิบายต่อได้ |
| 🎤 ฟัง-พูด | ฟังเสียงปกติ/ช้า แล้วพูดตาม ระบบให้คะแนนและไฮไลต์คำที่ผิด (ใช้ Chrome) |
| 👤 โปรไฟล์ | ชื่อเล่น อาชีพ เป้าหมาย เรื่องที่สนใจ และ "สิ่งที่ครู AI จำได้" (สรุปจุดผิดบ่อยอัตโนมัติหลังคุยจบ) แก้/ลบได้ |
| 🌐 แปล | แปลไทย ↔ อังกฤษ/เกาหลี/ญี่ปุ่น/จีน/เวียดนาม แบบคุยต่อหน้า (แบ่งจอ 2 ฝั่ง) หรือพิมพ์ มีเสียงอ่านและเก็บ ⭐ ประโยคได้ |
| 🤖 ครู AI | คุยเล่น · ตรวจประโยค · ซ้อมสัมภาษณ์ · ซ้อมประชุม · สั่งอาหาร/ท่องเที่ยว แก้คำผิดพร้อมคำอธิบายภาษาไทย |

ความคืบหน้าเก็บไว้ในเครื่องของผู้ใช้แต่ละคน (localStorage) ไม่ต้องล็อกอิน

## Deploy บน Vercel

1. ที่ vercel.com กด **Add New → Project** แล้วเลือก repo `english-coach`
2. Framework Preset เลือก **Other** ไม่ต้องตั้งค่า build แล้วกด **Deploy**
ส่วนคำศัพท์ ควิซ และฟัง-พูด ใช้ได้ทันทีโดยไม่ต้องมีคีย์

## เปิดใช้ครู AI (ใส่คีย์ทีหลังได้)

ใส่คีย์ **อย่างใดอย่างหนึ่ง** หรือทั้งคู่ ที่ Vercel → **Settings → Environment Variables**

| Key | ได้มาจาก | ค่าใช้จ่าย |
|---|---|---|
| `GEMINI_API_KEY` | [aistudio.google.com](https://aistudio.google.com) → Get API key | ฟรี (มีโควตาจำกัดต่อนาที/ต่อวัน) |
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) → API Keys | เติมเงินล่วงหน้า |
| `APP_PASSCODE` | ตั้งเองได้เลย เช่น `coach2026` | แนะนำให้ตั้ง กันคนอื่นใช้ครู AI |

- มีคีย์เดียว → ใช้ตัวนั้น
- มีทั้งสองคีย์ → ใช้ Claude เป็นหลัก ถ้าอยากใช้ Gemini ให้เพิ่ม `AI_PROVIDER` = `gemini`
- ตัวเลือกเสริม: `GEMINI_MODEL` (ค่าเริ่มต้น `gemini-3.5-flash-lite` สำรองด้วย `gemini-flash-latest`), `ANTHROPIC_MODEL` (ค่าเริ่มต้น `claude-haiku-5-5`)

เพิ่มหรือเปลี่ยนค่าแล้ว ต้องไปที่ **Deployments** กด ⋯ ที่อันล่าสุด → **Redeploy** ทุกครั้ง

> Gemini แบบฟรี: ข้อความที่ส่งอาจถูก Google นำไปใช้ปรับปรุงบริการ อย่าพิมพ์ข้อมูลส่วนตัวในแชตครู AI

## โครงสร้างไฟล์

```
index.html        หน้าเว็บหลัก
css/style.css     หน้าตาแอพ (รองรับโหมดมืด)
js/data.js        เนื้อหาภาษาอังกฤษ + ข้อมูลภาษา
js/data-langs.js  เนื้อหาภาษาเกาหลี ญี่ปุ่น จีน เวียดนาม
js/app.js         การทำงานของแอพทั้ง 5 ส่วน
api/tutor.js      ฟังก์ชันฝั่งเซิร์ฟเวอร์ (ครู AI, สรุปความจำ, แปลภาษา) เรียก Gemini หรือ Claude โดยเก็บคีย์ไว้ฝั่งเซิร์ฟเวอร์
```

## เสียงอ่านภาษาอื่น

เสียงอ่านใช้เสียงที่ติดตั้งในมือถือ ถ้าภาษาไหนไม่มีเสียง ให้ไปที่การตั้งค่ามือถือ → Text-to-speech แล้วดาวน์โหลดเสียงภาษานั้นเพิ่ม
